# BKID Workflowboost AutoCrop

<img src="BKID_AutoCrop/assets/BKID_AutoCrop_Icon.svg" width="96" alt="BKID AutoCrop 로고">

Windows Rhino의 실제 **BKID Workflowboost** 툴바에서 로고 버튼으로 투명 PNG를 저장합니다.

## 툴바 버튼

- **좌클릭**: 기존 1배 자동 크롭·PNG 저장을 바로 실행합니다.
- **우클릭**: ×2·×3·×4 해상도 선택 창을 엽니다. 배율을 선택하면 바로 저장하며, 취소하면 저장하지 않습니다.

배율은 캡처의 가로·세로 해상도에 적용합니다. 선택은 그 캡처에만 적용되어 다음 좌클릭은 1배입니다. 최종 크기는 자동 크롭에 따라 달라지며 투명 여백은 배율과 관계없이 사방 1px입니다.

## 설치 / 다시 설치 — 2.4

1. [설치 프로그램 다운로드 (.exe)](https://github.com/bkidoffice/BKID_Workflow_AutoCrop/raw/refs/heads/main/installers/BKID_AutoCrop_Setup_2.5.1.exe)
2. Rhino를 모두 종료하고 실행 → **설치 / 다시 설치**
3. 기존 설치가 있으면 **“설치되어 있습니다. 삭제하고 다시 설치할까요?”**에 예/아니요 선택
4. 예를 선택했거나 처음 설치하는 경우, 이어지는 Rhino Installer에서 **현재 사용자 설치** 완료

기존 설치에서 **예**를 선택하면 BKID 버전을 **백업 없이 삭제**합니다. **아니요**면 삭제·재설치 없이 그대로 유지합니다. 새 설치가 취소되거나 실패해도 이전 버전은 자동 복원되지 않습니다. 저장된 PNG와 Rhino 모델은 삭제하지 않습니다.

툴바를 자동 표시하는 것은 이 사용자 설정에서 첫 실행 때 한 번뿐입니다. 도킹한 뒤에는 Rhino가 저장한 위치와 표시 상태를 따르며, 매번 별도 툴바 창을 강제로 열지 않습니다. 닫은 툴바는 `BKIDAutoCrop`으로 다시 표시할 수 있습니다.

[자세한 설치·삭제 범위](installers/README_KO.md) · [개발자 빌드](plugin/README.md) · [캡처 엔진](BKID_AutoCrop/README_KO.md)

빌드·패키지·파일 삭제 검사는 통과했습니다. 실제 Windows 설치·레지스트리 처리와 Rhino 재시작 후 도킹 상태는 아직 미검증입니다. 이전 보고의 보안 프로그램 위협 탐지 원인도 미확인입니다.

2.4.1은 기존 툴바의 우클릭 연결도 갱신합니다. 업데이트 후에도 우클릭이 바로 저장된다면 `BKIDAutoCropRefresh`를 실행해 저장된 버튼 연결을 다시 읽을 수 있습니다.

2.4는 Rhino 6 초기 정식 SDK와 RUI 2.0을 기준으로 호환 경로를 보완했습니다. 마우스 설명은 **좌클릭 아이콘: 기본 해상도(1배)로 자동 크롭·PNG 저장**, **우클릭 아이콘: 해상도 선택 (×2·×3·×4)**으로 각각 표시하며, 기존에 저장된 버튼의 설명도 갱신합니다. Rhino 6에서 보고된 실행 실패의 정확한 원인은 F2 오류 기록 확인이 필요합니다.

2.4.1은 Rhino Installer 종료 코드만으로 설치 실패를 표시하지 않습니다. 실제 새 플러그인과 툴바 명령이 확인되면 403 반환 후에도 완료로 처리합니다. 마우스 아이콘별 설명을 분리하고 오래된 설명 캐시를 갱신합니다.


2.4.3: 2.4.1 기반으로 캡처 중 작업평면 Z축 표시를 숨겨 가장자리 판정에서 제외합니다. 성공·실패 후 원래 축 표시 상태를 복구합니다. 실제 Windows Rhino 실행은 미검증입니다.


2.5.1: 툴바 우클릭 → **저장 폴더 변경…**에서 PNG 저장 폴더를 지정합니다. `BKIDAutoCropFolder` 명령으로도 변경할 수 있습니다. 선택한 폴더는 Rhino 사용자 설정에 저장되어 재시작 후에도 좌클릭 1배·우클릭 모든 배율에 적용됩니다. 폴더 선택 취소는 기존 경로를 유지합니다. 폴더만 바꾸려면 배율을 고르지 않고 창을 닫으세요. Z축 캡처 제외 수정도 유지합니다. 실제 Rhino UI는 미검증입니다.
